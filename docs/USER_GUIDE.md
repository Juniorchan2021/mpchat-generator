## 一、软文工作台

**功能简介**：输入关键词、场景、卖点等参数，AI 自动生成一篇 SEO 优化的完整长文，并同步提供 SEO/GEO 评分、配图建议和导出选项。

### 入口位置

- 顶部导航栏点击「工作台」，或直接访问首页 `/`

### 使用步骤

**第一步：配置 AI 参数**

1. 点击页面左上角「AI 配置」区域
2. 从下拉框选择 AI 服务商（默认：Google Gemini）
3. 在「API Key」输入框中填入你的 API Key（点击右侧眼睛图标可切换显示/隐藏）
4. 选择要使用的模型版本（如 `gemini-2.5-flash`）

**第二步：填写文章配置**

| 字段 | 说明 | 是否必填 |
|------|------|----------|
| 关键词 | 文章核心关键词，如「内容营销」 | 必填 |
| 场景 | 选择文章场景，如「产品介绍」「行业洞察」 | 必填 |
| 文风 | 如「专业严谨」「轻松活泼」 | 必填 |
| 卖点 | 产品/品牌的核心卖点（可多选） | 选填 |
| 语言 | 文章输出语言（中文/英文等） | 必填 |

**第三步：一键生成文章**

1. 配置完毕后，点击「生成文章」按钮
2. 等待 AI 生成（通常 30-60 秒），生成过程中显示加载状态
3. 生成完成后，右侧出现五个 Tab 面板：
   - **文章预览**：查看 Markdown 格式文章
   - **SEO 分析**：关键词密度、标题结构等评分
   - **GEO 分析**：AI 可见性优化建议
   - **导出**：导出为 Markdown、HTML 等格式
   - **AI 检测**：检测文章的 AI 痕迹程度

**第四步：导出文章**

1. 点击「导出」Tab
2. 选择需要的格式（Markdown / HTML / 纯文本）
3. 点击对应「复制」或「下载」按钮

> **小贴士**：如果你使用了「SEO 选题助手」选定了标题，工作台页面顶部会出现一条紫色提示条，显示目标标题并提供「立即生成」按钮——点击该按钮生成的文章会严格采用你选定的标题作为 H1，而不是 AI 自动拟题。

## 二、多语言一键翻译

**功能简介**：将已生成或已优化的文章，一键翻译为其他语言版本，系统自动识别源语言并推荐翻译目标，全程保留 Markdown 格式。

### 入口位置

- **工作台**：生成文章后，在「文章预览」区域下方出现翻译按钮组
- **外部文章页**：完成优化后，在优化结果下方出现翻译按钮组（标题旁同时显示自动检测到的语言标签）

### 支持的翻译方向

| 源语言 | 可翻译为 |
|--------|----------|
| 简体中文 | 英文、繁体中文 |
| 英文 | 简体中文、繁体中文 |
| 繁体中文 | 简体中文、英文 |
| 其他 16 种语言（外部文章） | 简体中文、英文 |

### 使用步骤（工作台）

1. 在工作台完成文章生成后，切换到「文章预览」Tab
2. 滚动到预览区域下方，找到翻译按钮组（按钮内容根据文章语言自动变化）
3. 点击目标语言按钮，如「翻译为英文」
4. 等待翻译完成（按钮显示加载状态，不可重复点击）
5. 翻译结果显示在折叠面板中，可展开查看
6. 点击「复制」或「导出 Markdown」保存翻译结果

### 使用步骤（外部文章页）

1. 在外部文章页粘贴文章并完成优化（参见「外部文章检测与优化」章节）
2. 在优化结果下方，找到自动出现的翻译按钮组（标题旁会显示检测到的源语言标签，如「检测到：简体中文」）
3. 点击目标语言翻译按钮
4. 等待完成后，在折叠面板中查看并复制/导出翻译结果

## 三、多平台发布

**功能简介**：将生成或优化好的文章，一键发布到各内容平台，部分平台支持 API 直接发布，其余平台提供格式化预览供手动复制。

### 入口位置

- **工作台**：文章生成后，点击「发布」Tab
- **外部文章页**：文章优化后，页面下方出现「发布」面板区域

### 支持的发布平台

| 平台 | 发布方式 | 所需凭证 |
|------|----------|----------|
| Dev.to | API 直接发布 | Dev.to API Key |
| Hashnode | API 直接发布 | Token + Publication ID |
| Medium | API 直接发布 / 格式预览（无 Token 时自动降级） | Medium Integration Token（选填） |
| Paragraph | API 直接发布 | Paragraph API Key |
| LinkedIn | 格式预览（手动复制） | 无需 |
| Twitter/X | 推文线程预览（手动复制） | 无需 |
| 知乎 | Markdown 格式预览（手动复制） | 无需 |
| 微信公众号 | 纯文本预览（手动复制） | 无需 |

### 使用步骤（API 直发平台，以 Dev.to 为例）

1. 生成或优化好文章后，点击「发布」Tab（工作台）或找到发布面板（外部文章页）
2. 从平台列表中点击「Dev.to」
3. 在弹出的输入框中填入你的 Dev.to API Key
4. 点击「发布」按钮
5. 发布成功后，系统显示文章 URL 链接

### 使用步骤（格式预览平台，以 LinkedIn 为例）

1. 点击「发布」Tab，选择「LinkedIn」
2. 系统自动生成适合 LinkedIn 的纯文本格式（3000 字以内）
3. 点击「复制」按钮，然后前往 LinkedIn 手动粘贴发布

> **外部文章页发布说明**：外部文章页的发布面板中需要额外填写「文章标题」输入框，因为外部粘贴的文章标题不会自动提取。

## 四、外部文章检测与优化

**功能简介**：将你已有的博客文章粘贴进来，AI 自动进行 SEO/GEO 评分、提出改进建议，并支持五种优化模式一键重写，还可检测文章的 AI 创作痕迹。

### 入口位置

- 顶部导航栏点击「外部文章」，或访问 `/external`

### 使用步骤

**第一步：粘贴文章**

1. 在左侧「文章内容」文本框中粘贴完整的文章（支持 Markdown 和普通文本）
2. 在「目标关键词」输入框中填入该文章的核心关键词
3. 配置右上角 AI 参数（服务商 / API Key / 模型，同工作台）

**第二步：分析评分**

1. 点击「分析」按钮
2. 等待几秒，右侧出现 SEO 和 GEO 分析结果
3. 结果包含：
   - 环形分数图（0-100 分）
   - 逐项检查清单（绿色 ✓ 为通过，红色 ✗ 为需改进）

**第三步：选择优化模式**

点击「优化」按钮，从以下五种模式中选择：

| 优化模式 | 适用场景 |
|----------|----------|
| SEO 增强 | 提升搜索引擎排名，关键词密度和结构优化 |
| GEO 增强 | 提升 AI 搜索（如 ChatGPT 搜索）引用率 |
| 降低 AI 痕迹 | 让文章更像人工撰写，通过 AI 检测 |
| 扩写补充 | 增加文章字数和细节，补充论据 |
| 语言风格转换 | 调整表达风格（如专业→轻松） |

**第四步：查看 AI 检测报告（可选）**

1. 点击「AI 检测」按钮
2. 系统分析文章中的 AI 创作痕迹
3. 返回痕迹程度评分和具体说明

## 五、SEO 批量选题助手

**功能简介**：输入一个核心关键词，AI 一次性生成 20-50 个 SEO 爆款标题建议，每个标题附带搜索意图、难度评级和相关关键词，帮助你快速规划内容日历。

### 入口位置

- **独立页面**：顶部导航栏点击「选题」，或访问 `/ideation`
- **工作台快捷入口**：工作台页面「关键词」输入框旁边的「AI 选题」链接按钮

### 使用步骤（独立页面）

**第一步：输入参数**

1. 访问「选题」页面
2. 配置 AI 参数（服务商 / API Key / 模型）
3. 在「核心关键词」输入框填入关键词（必填），如「内容营销」「Web3 博客」
4. 在「行业领域」输入框填入所在行业（选填），如「SaaS」「电商」
5. 拖动「生成数量」滑块设置想要的标题数量（20-50 个，默认 30）

**第二步：生成选题**

1. 点击「生成选题」按钮
2. 等待 AI 生成（通常 30 秒内完成）
3. 页面下方出现标题列表，每行显示：
   - 标题文字
   - 搜索意图标签（如「信息型」「导航型」「商业型」）
   - SEO 难度星级（1-5 星）
   - 相关关键词标签组

**第三步：使用选定标题**

- **直接使用**：点击某个标题右侧的「使用此标题」按钮，页面自动跳转到工作台，关键词字段自动填入，工作台顶部出现紫色提示条显示目标标题
- **重新生成**：如果对结果不满意，修改参数后再次点击「生成选题」

> **说明**：离开选题页面后再返回，上次的选题列表会自动恢复（系统本地缓存），方便对比参考。

### 使用步骤（工作台快捷入口）

1. 在工作台「关键词」输入框旁点击「AI 选题」链接
2. 跳转到 `/ideation` 选题页面
3. 按上述步骤操作，选中标题后跳回工作台

## 六、Intercom QA 帮助中心生成

**功能简介**：输入产品功能描述，AI 自动生成标准化的问答（QA）文档，同时输出简体中文、繁体中文、英文三个语言版本，支持在线编辑、导出和一键上传到 Intercom 帮助中心。

### 入口位置

- 顶部导航栏点击「QA 生成」，或访问 `/intercom-qa`

### 使用步骤

**第一步：填写生成参数**

1. 访问「QA 生成」页面
2. 配置 AI 参数（服务商 / API Key / 模型）
3. 填写以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| 产品功能描述 | 详细描述你想生成 QA 的功能点 | 「MPChat 支持多轮对话，可以记住上下文…」 |
| 产品名称 | 你的产品名称 | 「MPChat」 |
| 语气风格 | 文档风格 | 「专业友好」「简洁直接」 |
| 生成数量 | 每个语言版本生成的 QA 对数 | 5-20，默认 10 |

**第二步：生成 QA 列表**

1. 点击「生成 QA」按钮
2. 等待 AI 生成（系统一次性生成简体中文、繁体中文、英文三个版本）
3. 结果区显示三个 Tab：「简体中文」「繁体中文」「English」

**第三步：编辑 QA 内容**

1. 在对应语言 Tab 下，浏览生成的 QA 卡片列表
2. 每张卡片包含：问题、答案、所属分类
3. 点击任意字段可直接编辑修改，修改实时保存

**第四步：导出文档（可选）**

在每个 Tab 下均可选择：
- **导出 Markdown**：格式为 `## Q: 问题` + `A: 答案`
- **导出 JSON**：标准数组格式，可用于程序化处理

**第五步：上传到 Intercom（可选）**

1. 在上传区域，填入你的 Intercom Access Token
2. 点击「读取 Collections」按钮，系统自动拉取你账号下的帮助中心分类列表
3. 从下拉菜单中为每个语言版本选择对应的 Collection（帮助中心分类）
4. 点击「全部上传」按钮
5. 页面显示上传进度（如「已上传 3/10」），完成后显示确认信息

> **注意**：API Token 仅在本次请求时使用，不会被服务器留存。

## 七、历史记录

**功能简介**：自动保存每次在工作台生成的文章，支持随时回溯查看，并可将历史文章重新加载到工作台继续使用。

### 入口位置

- 顶部导航栏点击「历史」，或访问 `/history`

### 使用步骤

1. 访问「历史」页面，查看所有历史生成记录（按时间倒序排列）
2. 每条记录显示：生成时间、关键词、文章标题预览
3. 点击某条记录的「加载到工作台」按钮，自动跳转到工作台并恢复当时的文章内容和参数
4. 如需清空历史，点击页面顶部「清空历史」按钮（操作不可撤销）

> **说明**：历史记录保存在浏览器本地，清除浏览器数据后记录会丢失，请注意及时导出重要文章。

## 附录：常见问题

**Q：生成文章报错「API Key 无效」怎么办？**

A：请检查 AI 配置中的 API Key 是否正确（点击眼睛图标确认内容）。不同服务商的 Key 格式不同，请确保选择了匹配的服务商。

**Q：翻译或生成超时了怎么办？**

A：单次请求最长等待 60 秒，超时后会显示错误提示。可尝试更换为响应速度更快的模型（如 `gemini-2.5-flash`），或缩短文章长度后重试。

**Q：为什么翻译按钮没有出现？**

A：翻译按钮仅在文章生成完成或优化完成后才会显示。工作台需要先完成文章生成；外部文章页需要先完成优化，才能看到翻译按钮。

**Q：发布到 Medium/Paragraph 失败怎么办？**

A：请确认 API Token 有效且有发布权限。Medium 需要使用「Integration Token」而非账号密码；如无 Token，Medium 会自动降级为格式预览模式，可手动复制到 Medium 编辑器。

**Q：Intercom QA 上传后在哪里查看？**

A：登录 Intercom 后台 → Help Center → 选择对应 Collection，上传的文章会出现在该分类下，状态为草稿，需手动发布。
